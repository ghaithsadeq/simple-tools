# 🤖 AI Learning Tools

AI Learning Tools is a collection of simple, safe, and educational tools designed to help students understand artificial intelligence concepts using modern AI platforms like Claude and Microsoft Copilot.

## 🎯 Purpose
This project aims to teach beginners:
- How AI models work  
- How to interact with AI safely  
- How to write effective prompts  
- How to use AI to support learning  
- How to build simple AI-assisted tools  

## 🧠 Tools Included
- **Prompt Helper** – Helps students write better prompts  
- **AI Study Assistant** – Uses AI to summarize lessons safely  
- **AI Explainer** – Explains concepts in simple language  
- **Safe AI Guide** – Teaches responsible and safe AI usage  

## 🛠️ Technologies Used
- Claude AI  
- Microsoft Copilot  
- Basic JavaScript  
- Simple HTML/CSS  
- Educational AI workflows
